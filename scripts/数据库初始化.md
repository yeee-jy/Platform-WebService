在系统初始部署时，建议至少创建以下两类基础用户，并遵循安全最佳实践：

---

### 一、必须创建的初始用户
#### 1. **超级管理员 (Super Admin)**
- **作用**：系统最高权限账户，用于创建角色/权限、初始化其他管理账户、配置系统参数
- **特征**：
  ```sql
  -- SQL 创建示例（密码应使用加密工具生成哈希值）
  INSERT INTO users (user_id, password_hash, name, status, created_by, updated_by) 
  VALUES ('SUPER_ADMIN', 'argon2$加密哈希值', '系统超级管理员', 'ENABLED', 'SYSTEM_INIT', 'SYSTEM_INIT');

  -- 关联角色（需先创建管理员角色）
  INSERT INTO roles (role_name, description) VALUES ('SUPER_ADMIN', '系统超级管理员角色');
  INSERT INTO user_role (user_id, role_id) VALUES ('SUPER_ADMIN', (SELECT role_id FROM roles WHERE role_name = 'SUPER_ADMIN'));
  ```

#### 2. **系统服务账户 (System Service Account)**
- **作用**：用于后台服务、定时任务等系统级操作，不绑定具体人员
- **特征**：
  ```sql
  INSERT INTO users (user_id, password_hash, name, status, created_by, updated_by)
  VALUES ('SYS_SERVICE', 'scrypt$加密哈希值', '系统服务账户', 'ENABLED', 'SUPER_ADMIN', 'SUPER_ADMIN');

  -- 关联最小必要权限角色（需先创建对应角色）
  INSERT INTO roles (role_name, description) VALUES ('SYSTEM_SERVICE', '系统服务角色');
  INSERT INTO user_role (user_id, role_id) VALUES ('SYS_SERVICE', (SELECT role_id FROM roles WHERE role_name = 'SYSTEM_SERVICE'));
  ```

---

### 二、推荐创建的基础角色（需在用户创建前初始化）
在 `roles` 表中预置以下角色：

| 角色名称         | 权限说明                          | 关联权限示例                     |
|------------------|-----------------------------------|----------------------------------|
| SUPER_ADMIN      | 全系统权限                        | 所有权限                         |
| SYSTEM_AUDITOR   | 系统审计权限                      | 查看日志、导出审计数据           |
| COLLEGE_ADMIN    | 院系级管理员（按需分学院创建）    | 管理本院用户、课程数据           |
| TEACHER          | 教师基础角色                      | 管理课程、录入成绩               |
| STUDENT          | 学生基础角色                      | 查看课表、提交作业               |

### 三、Python 初始化脚本示例
```python
from sqlalchemy import create_engine
from sqlalchemy.orm import Session
from models import Base, User, Role, Permission

def init_system_users(engine):
    Base.metadata.create_all(engine)
    
    with Session(engine) as session:
        # 1. 创建基础角色
        roles = [
            Role(role_name="SUPER_ADMIN", description="系统超级管理员"),
            Role(role_name="SYSTEM_AUDITOR", description="系统审计员"),
            Role(role_name="COLLEGE_ADMIN", description="院系管理员"),
            Role(role_name="TEACHER", description="教师角色"),
            Role(role_name="STUDENT", description="学生角色")
        ]
        session.add_all(roles)
        
        # 2. 创建超级管理员（密码建议从环境变量读取）
        super_admin = User(
            user_id="SUPER_ADMIN",
            password_hash=generate_password_hash(os.getenv("SUPER_ADMIN_PWD")),  # 需实现密码哈希函数
            name="系统超级管理员",
            status="ENABLED",
            created_by="SYSTEM_INIT",
            updated_by="SYSTEM_INIT"
        )
        super_admin.roles = [roles[0]]  # 关联SUPER_ADMIN角色
        session.add(super_admin)
        
        # 3. 创建系统服务账户
        service_account = User(
            user_id="SYS_SERVICE",
            password_hash=generate_password_hash(os.getenv("SERVICE_ACCOUNT_PWD")),
            name="系统服务账户",
            status="ENABLED",
            created_by="SUPER_ADMIN",
            updated_by="SUPER_ADMIN"
        )
        service_account.roles = [roles[1]]  # 关联审计角色
        session.add(service_account)
        
        session.commit()

if __name__ == "__main__":
    engine = create_engine('mysql+pymysql://user:password@localhost/edu_system')
    init_system_users(engine)
```

### 四、安全实践建议
1. **密码策略**：
   - 超级管理员密码长度应≥16位，包含大小写字母、数字、特殊符号
   - 使用 Argon2 或 BCrypt 等现代哈希算法（**不要使用MD5/SHA1**）
   - 首次登录强制修改密码

2. **权限控制**：
   ```sql
  -- 超级管理员角色应拥有所有权限
  INSERT INTO role_permission 
  SELECT role_id, perm_id FROM roles, permissions 
  WHERE role_name = 'SUPER_ADMIN';
   ```

3. **审计跟踪**：
   ```sql
  -- 建议创建审计专用表
  CREATE TABLE audit_logs (
      log_id BIGINT AUTO_INCREMENT PRIMARY KEY,
      user_id VARCHAR(20) NOT NULL,
      action_type VARCHAR(50) NOT NULL,
      target_id VARCHAR(20),
      created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
      FOREIGN KEY (user_id) REFERENCES users(user_id)
  );
   ```

4. **后续步骤**：
   - 通过超级管理员创建各院系管理员
   - 由院系管理员初始化本部门的教师/学生账户
   - 定期审计系统账户（建议每月一次）

建议在正式部署前进行安全渗透测试，确保初始账户不会被暴力破解。
